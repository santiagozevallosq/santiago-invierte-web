# Santiago Invierte — Plataforma Web Oficial (2026)

Propuesta web integral y personalizada para **Santiago Invierte** (Santiago Zevallos — Economista PUCP • Magíster en Finanzas • Consultor y Docente en IA Aplicada).

Diseñada con **estética editorial de autor (Bespoke 2026)**, eliminando plantillas genéricas de IA e incorporando rigor analítico, simuladores de impacto y hojas de trabajo interactivas.

---

## Estructura de la Plataforma
- **Portada (`/`)**: Hero editorial, artefacto interactivo de auditoría de contratos/balances, dossier de cátedra de Santiago Zevallos, simulador de tiempo recuperable y selector de modalidades.
- **Cursos (`/cursos`)**: 5 programas prácticos especializados (Finanzas, Legal, Gestión Pública, Contratos y Minutas).
- **Servicios (`/servicios`)**: Propuesta institucional in-house para empresas, estado y universidades, con metodología de transferencia en 30-60 días.
- **Recursos (`/recursos`)**: Visor de plantillas de prompts auditadas y solicitud de manuales metodológicos en PDF.
- **Sobre Mí (`/sobre-mi`)**: Trayectoria y respaldo académico PUCP.
- **Contacto (`/contacto`)**: Asistente interactivo con generación dinámica de enlaces a WhatsApp.

---

## Cómo Ejecutar en Local

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```
3. Compilar para producción:
   ```bash
   npm run build
   ```
